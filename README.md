## Исходные данные

Массив из 7 чисел — количество новых слов, выученных за каждый день:

```js
const wordsPerDay = [12, 55, 8, 63, 30, 5, 72];
```

Пороговые значения вынесены в константы:

| Константа | Значение | Смысл |
|---|---|---|
| `HIGH_PROGRESS_LIMIT` | 50 | день с высоким прогрессом: больше 50 слов |
| `LOW_PROGRESS_LIMIT` | 10 | день с малым прогрессом: не больше 10 слов |
| `GOOD_AVERAGE_LIMIT` | 30 | порог среднего для фразы «Отличный темп» |

## Что реализовано

### Ввод/вывод

- `prompt` — запрашивает имя пользователя (если ввод пустой или отменён, подставляется «Гость»).
- `alert` — приветствие по имени и итоговое сообщение.
- `console.log` — подробная статистика в консоли браузера.

### Функции

| Функция | Что делает |
|---|---|
| `findMax(numbers)` | возвращает максимальное число в массиве (лучший день) |
| `filterAbove(numbers, limit)` | возвращает только числа больше заданного порога (дни с высоким прогрессом) |
| `sumArray(numbers)` | возвращает сумму всех чисел (всего выучено слов) |

### Условные конструкции и циклы

- Цикл `for` проходит по всем дням и находит дни с малым прогрессом (≤ 10 слов), по ним считается количество и процент.
- Условие `if` проверяет среднее: если оно больше 30, выводится сообщение «Отличный темп изучения языка!».
- Условие `if` обрабатывает пустой ввод имени.

## Результат работы

**Для данных `[12, 55, 8, 63, 30, 5, 72]`:**

| Показатель | Значение |
|---|---|
| Всего выучено слов | 245 |
| Дней с высоким прогрессом (> 50) | 3 (55, 63, 72) |
| Дней с малым прогрессом (≤ 10) | 2 (дни 3 и 6) |
| Процент дней с малым прогрессом | 28.6% |
| Среднее за день | 35 слов |
| Лучший день | 72 слова |

**Окно `alert`:**

```
Всего выучено 245 слов, в 3 днях прогресс был высоким
```

**Консоль:**

```
Дней с малым прогрессом (≤ 10): 2 (дни: 3, 6)
Процент дней с малым прогрессом: 28.6%
Среднее за день: 35 слов
Отличный темп изучения языка!
```

## Дополнительно: вывод на страницу

Кроме обязательных `prompt`, `alert` и `console.log`, результат показывается на самой странице в секции «Мой прогресс в изучении слов»:

- приветствие по введённому имени;
- четыре карточки: всего слов, дни с высоким прогрессом, дни с малым прогрессом (с процентом), среднее за день;
- плашка «Отличный темп изучения языка!», если среднее больше 30;
- диаграмма «Слов по дням» — полоса на каждый день с пометкой «высокий», «средний» или «малый» (цвет дублируется текстом);
- в консоли данные выводятся таблицей через `console.table`.

Скрипт запускается после загрузки страницы (`load`), поэтому страница успевает отрисоваться до появления окна с вопросом об имени. Блок адаптивный: карточки статистики идут в 4, 2 и 1 колонку на десктопе, планшете и мобильном.
